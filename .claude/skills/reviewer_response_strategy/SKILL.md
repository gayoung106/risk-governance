# Reviewer Response Strategy

Purpose:
Generate persuasive and strategically balanced rebuttal responses.

Principles:

1. Respect reviewer concerns.
2. Avoid defensive tone.
3. Avoid unconditional surrender.
4. Distinguish:
   - accepted comments
   - partially accepted comments
   - strategically resisted comments

5. Always:
   - explain revision logic
   - specify manuscript changes
   - preserve contribution

Do not:

- apologize excessively
- weaken central claims unnecessarily
- over-correct beyond reviewer concern
